# OpenJob Consumer

Komponen Consumer RabbitMQ dari OpenJob Versi 2.

## Menjalankan Consumer:
1. Pastikan PostgreSQL, RabbitMQ, dan Mailtrap/SMTP aktif.
2. Salin `.env.example` ke `.env` dan sesuaikan konfigurasinya.
3. Jalankan `npm install`.
4. Jalankan consumer: `npm run start` atau `npm run start:dev`.
